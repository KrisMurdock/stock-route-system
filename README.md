# 持盈路线 · 交易纪律工作台

一个可迭代的股票交易路线工作台，适用于 **A 股 + 港股通**。以计划盈亏比为主，持仓时长用于复盘，不预设固定周期。

## 初始路线

```mermaid
sequenceDiagram
  participant A as 01 · 交易前提
  participant B as 02 · 选好股 / 找龙头
  participant C as 03 · 低位确认 / 盈亏比
  participant D as 04 · 分批打入
  participant E as 05 · 持仓管理
  participant F as 06 · 目标卖出
  Note over A: 01.1 市场边界 / 01.2 风险预算
  A->>B: 确认市场与预算
  Note over B: 比较范围、强度与逻辑、龙头地位
  B->>C: 龙头逻辑成立，进入观察
  loop 每一个新确认的低点
    Note over E: 退出检查、现金与整仓风险、待处理退出
    alt 目标达到或逻辑失效
      break 退出优先，结束本轮买入
        E->>F: 暂停补仓，按计划退出
        Note over F: 目标判断、挂单跟踪、退出受阻
        F->>F: 跟踪成交；受阻则继续管理
      end
    else 未触发退出，继续评估
      Note over C: 低位口径、低点证据、止跌条件
      alt 证据、盈亏比与预算均通过
        C->>D: 确认低点，投入一笔
        Note over D: 计划内金额、新低点、次数上限
        D->>E: 记录成交，更新持仓
      else 待确认或条件不通过
        C-->>C: 继续观察，暂不买入
      end
      E-->>C: 等待下一个低点，重新评估
    end
  end
  F-->>A: 完成退出后复盘，迭代下一版路线
```

叶子规则统一使用“通过 / 待确认 / 不通过”。待确认不生成买入动作；不通过进入观察或退出路径。挂单、部分成交和全部成交是不同状态。

## 运行

页面以 Mermaid 时序图作为主画布：六个参与者对应大节点，编号注释对应边界条件。默认展开选中节点，也可展开全部边界。点击图中节点或条件打开编辑面板，支持键盘 Enter / 空格、缩放与适应画布。窄屏使用可关闭的编辑浮层。

“编辑节点 / 编辑条件”可修改名称和说明，规则定义在所有候选间共用，判断状态仍按候选独立。修改定义使所有候选的对应节点退回待确认，同时撤销未执行低点；历史日志和版本快照保留当时的定义。规则字段不能为空，名称最多 60 字，说明最多 400 字。

时序图包括规划中的退出受阻路径，当前执行按钮仍为低点、买入成交、目标挂单和全额卖出成交的手动记录；图中路径不代表自动订单功能。

已提交可直接部署的静态资源。在本目录运行：

```bash
python3 -m http.server 4173
```

点击交易前提、低位、分批、持仓或卖出节点，可以编辑当前候选的市场、入场价、失效价、目标价、每股往返费用与滑点、最低盈亏比及市场核验状态。最低盈亏比默认待设置，费用不能留空（填 0 表示暂不计）。

计划盈亏比 =（目标价 − 入场价 − 费用）÷（入场价 − 失效价 + 费用）。例如 100 入场、95 失效、110 目标、费用 0 时为 2:1；这是计算示例，门槛由用户设置。这里只计算本笔计划，补仓仍须复核整仓风险。港股通使用港币报价估算，人民币实际结算还受汇率和真实费用影响。

10% 保留为可编辑的初始止盈模板，通过按钮填入目标价，不自动覆盖已保存计划。卖出记录使用所选候选的目标价对应涨幅，用户手动输入的涨幅不代表券商核验的净收益。

低点确认绑定候选及当前计划，一次确认只支持一笔买入；编辑计划使未执行确认失效。计划及叶子状态按候选隔离，日志保留操作当时的计划快照，新版本保存当前计划快照，历史日志不会被新计划覆盖。

所有数据保存在当前浏览器的 `localStorage` 中，不跨设备同步，也不连接行情或交易账户。市场核验依赖用户确认；系统未接入港股通资格或交易日实时校验。挂卖单按钮仅记录用户操作，未向券商发送订单。

Mermaid 版本锁定并与站点一起托管；按需加载时序图代码，不依赖外部 CDN。修改 `sequence-view.js` 后需重新构建。核心计算与路线模型的单元测试、现有交易链路与新版图表交互 E2E 均纳入 `npm test` / `npm run test:e2e`。
